# EEPATHO — Atlas Géo-Santé (version publique)

Atlas communal (France métropolitaine, 2017-2024) des variables territoriales du projet EEPATHO :
population, contexte social, accès aux soins, eau potable, qualité de l'air, typologies, radon.

**Version publique** : seules des données publiques sont incluses (INSEE, ARS / SISE-Eaux, Ineris, IRSN, DREES…).
Les données patients EEPATHO (prévalence, incidence, étiologies, parcours de soins) ne sont **pas** dans ce dépôt.

- `index.html` — page d'accueil
- `atlas.html` — l'atlas (MapLibre GL JS)
- `data/` — une variable par fichier JSON, `data/_index.json` liste les variables publiées

Équipe Géo-Santé — Centre Léon Bérard · SHAPE-Med Lyon.
